# 본문 규칙

특별히 적지 않으면 `SKILL.md` 본문과 참조 파일에 적용한다.

중복, 커스텀 태그, 한국어 문법은 저장소 `CLAUDE.md` 의 문서 절이, 표기와 용어는
표기 절과 용어 표기 절이 소유한다. 그쪽도 함께 적용된다.

## W1

도구 이름을 쓰지 않고 행동으로 서술한다.

**판정 기준** -- 사람이 판정한다. 무엇을 하라고만 적고 무엇으로 하라고 적지
않는다. 실행 파일 이름은 도구 이름이 아니므로 그대로 적는다.

```
위반:  Read 툴로 trigger.md 를 읽는다
통과:  trigger.md 를 읽는다
통과:  python3 checks/run.py 를 실행한다
```

**근거** -- 하네스마다 도구 이름이 다르다. 한쪽 이름을 쓰면 다른 쪽에서 지시가
성립하지 않는다.

## W2

`SKILL.md` 만 읽고 무엇을 언제 왜 하는지 확정돼야 한다.

**판정 기준** -- 사람이 판정한다. 셋이 다 있어야 통과한다. 이 스킬이 무엇을
하는지, 언제 발동하는지, 무엇을 막으려고 있는지다.

**근거** -- `SKILL.md` 가 명세를 겸한다. 근거가 없으면 나중에 고칠 때 무엇을
지키려던 것인지 몰라 아무렇게나 고친다.

## W3

지시는 단정형으로 쓴다.

**적용 범위** -- 스킬의 절차와 지시 문장. 설명과 근거와 기록에는 적용하지 않는다.

**판정 기준** -- 사람이 판정한다. 판단 여지를 남기는 표현이 붙으면 위반이다.
"가급적", "되도록", "권장한다", "~것이 좋다", "필요하면", "가능하면" 이 여기
해당한다. 조건 자체는 위반이 아니다. 조건을 모호하게 두는 것이 위반이다.

```
위반:  필요하면 참조 파일로 나눈다
통과:  다섯 단계를 넘으면 참조 파일로 나눈다
```

**근거** -- 권고형은 판단 여지로 읽혀 상황마다 다르게 처리된다.

## W4

각 규칙은 규칙 문장, 판정 기준, 근거 순으로 적고 근거는 한두 문장을 넘지 않는다.
서사로 풀지 않는다.

**적용 범위** -- `standards/skills/` 의 규격 문서.

**판정 기준** -- 사람이 판정한다. 셋 중 하나가 빠지거나 순서가 다르면 위반이다.
기본 적용 범위와 다른 규칙은 규칙 문장 다음에 적용 범위를 한 줄 덧붙인다. 예시는
판정 기준 안에 둔다.

**근거** -- 항목마다 구성이 다르면 쓰는 쪽도 읽는 쪽도 매번 다르게 처리한다.

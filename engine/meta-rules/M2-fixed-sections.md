## 판정 기준

결함: `rules/` 의 파일이 아래 세 섹션을 순서대로 갖지 않는다.

```
## 판정 기준
## 수정 지침
## 예시
```

세 섹션 외의 `##` 헤딩이 있어도 결함이다. 각 섹션은 비어 있지 않아야 한다.

## 수정 지침

빠진 섹션을 채운다. 예외 조항은 별도 섹션으로 만들지 않고 `판정 기준` 안에 넣는다.
판정 기준과 예외가 갈라져 있으면 판정하는 쪽이 한쪽만 읽는다.

## 예시

통과 -- 판정 기준, 수정 지침, 예시 순서로 세 섹션
결함 -- 판정 기준, 근거, 예외, 예시 네 섹션

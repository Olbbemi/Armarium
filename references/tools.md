## 코드 인텔리전스 (code intelligence)

> 코드베이스 탐색, 검색, 구조 파악에 사용하는 툴.
> 텍스트 출력 -> LLM이 직접 분석 / 이미지·dot 출력 -> 사용자 시각 확인용

| 언어 | 도구 | 용도 · 출력 |
|------|------|------------|
| 공통 | `ripgrep (rg)` | 코드베이스 내 패턴/문자열 초고속 검색. 텍스트 출력 |
| 공통 | `fd` | 파일명/경로 기반 빠른 파일 탐색. 텍스트 출력 |
| 공통 | `tree` | 디렉토리 구조 시각화. 텍스트 출력 |
| 공통 | `universal-ctags` | 함수/클래스/심볼 인덱싱 및 위치 추적. 텍스트 출력 |
| 공통 | `graphviz` | 의존성/호출 그래프 시각화. 이미지/dot 출력 (사용자 확인용) |
| Python | `pycallgraph2` | 함수 호출 그래프 생성. 이미지 출력 (사용자 확인용) |
| C++ | `include-what-you-use` | 헤더 의존성 분석 및 불필요한 include 탐지. 텍스트 출력 |
| Rust | `cargo-deps` | 크레이트 의존성 그래프 생성. 이미지/dot 출력 (사용자 확인용) |

## 정적 분석 (static analysis)

| 언어 | 도구 | 용도 |
|------|------|------|
| 공통 | `tree-sitter` | 다중 언어 AST 파싱. 코드 구조를 트리 형태로 추출, 언어 무관하게 문법 분석 가능 |
| Python | `ast` (내장) | Python 코드를 AST로 파싱. 별도 설치 불필요 |
| Python | `pylint` | 코드 품질, 스타일, 버그 패턴 종합 분석 |
| Python | `mypy` | 타입 힌트 기반 정적 타입 체크 |
| Python | `ruff` | pylint/pyflakes 대체 가능한 초고속 린터 (Rust 기반) |
| Python | `bandit` | 보안 특화. SQL 인젝션, 하드코딩 credentials, 약한 암호화, SSL 검증 비활성화 등 탐지 |
| C++ | `clang-tidy` | 정적 분석 + 보안 패턴 탐지. clang 기반으로 정확도 높음 |
| C++ | `cppcheck` | 메모리 오류, 버퍼 오버플로, 미정의 동작 등 버그 패턴 분석 |
| C++ | `flawfinder` | 보안 특화. 위험 함수 패턴 탐지 (버퍼 오버플로, 포맷 스트링 등). 오탐 시 LLM이 컨텍스트 기반으로 재판단 |
| Rust | `clippy` | 정적 분석 + 린팅. 관용적이지 않은 코드, 버그 패턴, 성능 이슈 탐지 |
| Rust | `cargo-audit` | 의존성 취약점 체크. 알려진 보안 이슈가 있는 크레이트 탐지 |

## LSP (Language Server Protocol) -- 코드 작성 중 실시간 언어 분석

> 로컬에서 실행되는 언어 분석 서버. 외부 네트워크 연결 없음.
> LLM이 코드를 텍스트가 아닌 언어 구조로 이해할 수 있게 도와줌.
> 문법 오류, 타입 불일치, 심볼 정의 위치, 자동완성 등 실시간 피드백 제공.

| 언어 | 도구 | 특징 |
|------|------|------|
| Python | `pylsp` | Python Language Server. 타입 체크, 자동완성, 정의 위치 추적 |
| C++ | `clangd` | clang 기반 C++ Language Server. 정확도 높음. include-what-you-use와 연동 가능 |
| Rust | `rust-analyzer` | Rust 공식 Language Server. cargo와 긴밀하게 연동 |

## 문서화 (documentation)

### 코드 문서 자동 생성

| 언어 | 도구 | 특징 · 출력 |
|------|------|------------|
| Python | `pdoc` | 주석 기반 API 문서 자동 생성. 설정 없이 바로 사용 가능. HTML 출력 (사용자 확인용) |
| C++ | `doxygen` | 주석 기반 API 문서 자동 생성. C/C++ 업계 표준. HTML/PDF/XML 출력 (사용자 확인용) |
| Rust | `cargo doc` (내장) | `///` 주석 기반 API 문서 자동 생성. 별도 설치 불필요. HTML 출력 (사용자 확인용) |

| 도입 후보 | 채택 조건 |
|-----------|----------|
| `sphinx` | pdoc보다 기능이 많은 Python 문서화 툴. 주석 외에 별도 .rst 문서 파일 작성도 가능해 대규모 프로젝트에 적합. pdoc으로 부족할 때 사용 |

### 다이어그램 / 시각화

> 우선순위: mermaid (md 안 직접 임베드 가능) -> plantuml (mermaid로 표현 힘들고 별도 파일/참조가 허용되는 경우)

- `mermaid` -- md 파일 안에 텍스트로 작성하면 다이어그램으로 렌더링. 플로우차트, 시퀀스, 클래스 다이어그램 등 지원. 별도 파일 불필요. **다이어그램의 기본 선택**
- `graphviz` -- DOT 언어로 그래프 작성. 의존 그래프, 콜 그래프 등 복잡한 그래프 시각화에 적합. 이미지/dot 출력 (사용자 확인용). 코드 인텔리전스 섹션 참조
- `plantuml` -- UML 전체 (배치, 컴포넌트, 사용 사례 등) 지원. 별도 파일로 출력되므로 md 에 직접 임베드 불가. 외부 참조 형태로 사용. mermaid로 표현하기 힘든 고급 UML 이 필요할 때 채택

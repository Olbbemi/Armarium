# code-analyze

코드의 4가지 측면 분석: 구조, 품질, 변경 영향도, 로직 요약.

## 하위 스킬

에이전트 정의는 플러그인 루트 `agents/` 에 있고, 플러그인 시스템이 자동 발견해 Task 의 `subagent_type`(bare 이름)으로 호출된다.

| 분석 | 에이전트 (subagent_type) | 정의 파일 | 역할 |
|------|--------------------------|-----------|------|
| 구조/아키텍처 | `code-analyze-structure` | `agents/code-analyze-structure.md` | 디렉토리·모듈·의존성·진입점·데이터 흐름 |
| 품질 | `code-analyze-quality` | `agents/code-analyze-quality.md` | 복잡도·중복·데드코드·안티패턴 |
| 변경 영향도 | `code-analyze-impact` | `agents/code-analyze-impact.md` | 지정 대상 수정 시 영향 받는 범위 |
| 로직 요약 | `code-analyze-summary` | `agents/code-analyze-summary.md` | 코드 동작을 사람 말로 서술 |

## 실행 순서

### 1. 분석 종류 결정

호출 시 사용자가 분석 종류(`structure`/`quality`/`impact`/`summary`)를 명시하면 그대로 쓴다. 명시하지 않으면 대화 맥락으로 적절한 분석을 자동 선택한다. 맥락이 모호하면 사용자에게 어떤 분석을 원하는지 물어 결정한다.

### 2. 분석 대상 경로 결정

대상 경로는 대화 맥락에서 결정한다. 명확하지 않으면 사용자에게 묻는다. 결정된 경로를 모든 에이전트 입력으로 전달한다.

### 3. 에이전트 호출

결정된 분석 종류마다 대응하는 `code-analyze-<종류>` 에이전트를 Task 도구의 `subagent_type` 으로 호출한다. 선택이 1개면 단일 호출, 2개 이상이면 한 응답 안에 함께 넣어 병렬 호출한다. 선택될 수 있는 호출 항목은 다음과 같다.

- [ ] 에이전트 `code-analyze-structure`: 일반 호출. 입력: 분석 대상 경로. 출력: 마크다운 리포트 본문 반환 -> 메인이 취합
- [ ] 에이전트 `code-analyze-quality`: 일반 호출. 입력: 분석 대상 경로. 출력: 마크다운 리포트 본문 반환 -> 메인이 취합
- [ ] 에이전트 `code-analyze-impact`: 일반 호출. 입력: 분석 대상 경로 + 변경 후보. 출력: 마크다운 리포트 본문 반환 -> 메인이 취합
- [ ] 에이전트 `code-analyze-summary`: 일반 호출. 입력: 분석 대상 경로. 출력: 마크다운 리포트 본문 반환 -> 메인이 취합

<PENETRATE>
분석이 2개 이상 선택되면 해당 에이전트들을 한 응답 안에서 Task 로 병렬 호출한다.
</PENETRATE>

### 4. 결과 취합

모든 에이전트 완료 후 결과를 통합해 사용자에게 제시한다. 섹션 헤더(`## 구조`, `## 품질` 등)로 각 분석 결과를 구분한다. 에이전트 반환 본문에 `&`/`<`/`>` 가 HTML 엔티티로 이스케이프됐으면 표시 전 원복한다.

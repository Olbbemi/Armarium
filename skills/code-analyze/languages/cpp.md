# C++ 언어 규칙

## 노드 단위 (survey · structure 공통)

C++ 는 선언과 정의가 분리되므로, **같은 basename 의 헤더/소스 짝**(`Foo.hpp`+`Foo.cpp`, `Foo.h`+`Foo.cc`/`.cpp`)을 **한 노드**로 묶는다. 노드=파일 미러에서 이 짝은 파일 2개지만 노드 1개다.

- survey: 인벤토리/개수를 셀 때 이 짝을 한 노드로 센다 -- 헤더에 선언, 소스에 정의된 같은 타입/함수를 이중 계상하지 않는다.
- structure: 이 짝을 한 문서로 묶어 채운다 -- 선언의 시그니처 + 정의의 본문 속성(역할/불변식/예외)을 한 노드 문서에.
- 짝 없는 헤더-온리(템플릿/인라인 전용)나 소스-온리 파일은 그 하나가 곧 한 노드다.

## 한정자 어휘 (structure)

범용 "가시성 / 수명 / 디스패치 축의 언어별 한정자"를 C++ 에서 채우는 구체 키워드. 전체 시그니처에 해당 한정자를 빠짐없이 남긴다(as-built).

- 가시성: `public` / `protected` / `private`.
- 수명 · 저장: `static`, `constexpr`, `constinit`, `inline`, `const`, `mutable`, `thread_local`.
- 디스패치: `virtual`, `override`, `final`.
- 계약 · 변환: `noexcept`, `explicit`.

## 속성 심화 (structure) -- C++ 고유 축

범용 "속성 3(역할 / 불변식 / 예외)"에 더해, 각 타입/함수에서 아래 C++ 축을 잡는다. 리팩토링 · 수명 버그 · 써야 할 테스트 지점이 여기서 드러난다(facet 이 "무엇이 있다"를 넘어 "어디가 위험한지"까지 가게 하는 축).

- **소유권 / 수명**: 멤버 · 인자 · 반환이 자원을 어떻게 쥐는지 명시한다 -- `unique_ptr`(단독 소유) / `shared_ptr`(공유 소유) / `weak_ptr`(비소유 관찰) / raw 포인터 · 참조(비소유 관찰) / RAII 핸들. 비소유 포인터 · 참조는 **그 수명이 무엇에 묶이고 언제 댕글링되는지**를, move-in 인자는 **use-after-move 주의**를 함께 적는다.
- **값 시맨틱 (rule of 0/3/5)**: 특수 멤버 -- 복사/이동 생성 · 대입, 소멸자 -- 의 존재 여부와 `=default` / `=delete` 상태, 거기서 나오는 **복사 가능 / 이동 가능 / 고정(pinned)** 여부. 이동 후 사용 위험, 테스트 픽스처에서 복사가 안전한지의 근거.
- **const 정확성**: 메서드의 const 여부(관찰 vs 변경), 인자의 `const&` / 값 / 비const& 구분, `mutable` 멤버. 어느 연산이 상태를 안 바꾸는지 = 불변식 · 스레드 안전 추론의 바탕. 관찰만 하는 메서드가 non-const 면 그 불일치를 짚는다.
- **인터페이스 / 추상 식별**: 순수 가상(`= 0`) 멤버가 있으면 이 타입이 **추상/인터페이스 타입**(직접 인스턴스화 불가, 파생이 채움)임을 표시한다. 다형적으로 삭제되는 기반 클래스의 **소멸자 virtual 여부**(다형 삭제 안전성)도 남긴다. 파생 -> 기반의 상속/구현 관계는 구조의 상속 관계로 적는다. 단 이를 "포트/어댑터" **역할로 해석하거나 포트 <- 구현 대응표를 만드는 것은 architecture 몫**이라 여기서 하지 않는다(같은 사실을 두 고도에서 이중 소유 방지 -- structure 는 낱개 구조 사실까지, 역할 지도는 architecture).

> 경계(structure vs invariants): 위는 모두 **낱개(per-node) 사실**이다. "모든 자원은 RAII 로 관리한다" 같은 **전칭 전역 규약**은 invariants 의 단일 소스이니, 여기서 전역 주장으로 올리지 말고 invariants 가 잡아 링크하게 둔다(structure = 낱개, invariants = 창발적 전역).

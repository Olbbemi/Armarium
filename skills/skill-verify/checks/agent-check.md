# 에이전트 검증

이 파일은 overview.md 의 실행 순서에 따라 메인 Claude 가 직접 로드한다.

대상 스킬이 `skill-writing §10 에이전트 구성` 규약을 따르는지 확인한다.
조건부 검증이다. overview.md 본문에 에이전트 호출 지시가 있으면 진행하고, 없으면 "해당 없음" 으로 보고하고 종료한다.

---

## 체크리스트

### 정의 위치 (플러그인 루트 agents/)

- [ ] overview.md 가 호출하는 각 에이전트의 정의 파일이 플러그인 루트 `agents/` 아래에 존재한다 (플러그인 루트 = 대상 스킬 디렉토리의 상위 두 단계)
- [ ] 각 에이전트가 독립된 파일로 분리되어 있다 (한 파일에 여러 에이전트 정의 금지)

### 정의 파일 형식

각 에이전트 정의 파일에 대해 다음을 확인한다.

- [ ] 프론트매터가 존재한다
- [ ] 프론트매터에 `name` 필드가 있다
- [ ] 프론트매터에 `description` 필드가 있다
- [ ] 프론트매터에 `tools` 필드가 있다
- [ ] 프론트매터 `name` 값이 파일명(확장자 제외)과 일치한다
- [ ] 본문에 시스템 프롬프트 (에이전트가 어떻게 작업할지) 가 작성되어 있다

### overview.md 에이전트 호출 항목

overview.md 의 에이전트 호출 항목마다 다음을 확인한다.

- [ ] 에이전트 이름이 명시되어 있다
- [ ] 호출 형태(일반 / 백그라운드)가 명시되어 있다
- [ ] 입력으로 전달할 내용이 명시되어 있다
- [ ] 기대 출력(저장 파일 경로 또는 반환 텍스트 형식)이 명시되어 있다
- [ ] 호출 방식이 Task 도구다 (별도 스크립트 호출 패턴 `claude -p` 등을 사용하지 않는다)

### 서브에이전트 직접 Write 설계

기대 출력이 "반환 텍스트" 가 아니라 "저장 파일 경로" 인 호출 항목마다 확인한다. 해당 항목이 없으면 이 절은 "해당 없음" 으로 적는다.

- [ ] 직접 Write 가 `skill-writing §10` 의 예외 (a) 부피 / (b) 병렬 팬아웃 중 하나에 해당한다
- [ ] 그 저장 경로가 사전 허용 경로임이 overview 에 명시되어 있거나, 사전 준비 단계에서 쓰기 가능 여부를 확인하는 절차가 있다

백그라운드 서브에이전트는 권한 프롬프트를 띄우지 못해 사전 허용되지 않은 경로에는 Write 가 조용히 거부된다. 통지는 오는데 파일이 없어 그다음 단계가 원인을 알 수 없는 실패를 낸다.

### 호출 명단 일치

- [ ] overview.md 가 호출하는 모든 에이전트 이름이 플러그인 루트 `agents/` 에 정의 파일로 존재한다 (플러그인 루트 agents/ 는 플러그인 내 여러 스킬이 공유하는 풀이므로, 이 스킬이 안 쓰는 정의 파일이 있어도 실패로 보지 않는다)

## 결과 보고

체크리스트 각 항목을 실행한 뒤 아래 형식으로 출력한다.

```
**검증 대상 에이전트:** <이름 목록>

- [o] 항목명
- [x] 항목명 -- 실패 이유
  위치: <파일 경로>

**결론:** 통과/실패 -- 통과 N / 실패 N
**수정 제안:** (실패 항목별 수정 방법, 없으면 생략)
```

<FORBIDDEN>
`[x]` 표기 항목이 하나라도 있는데 결론을 통과로 적지 않는다.
</FORBIDDEN>

조건에 해당하지 않아 검증을 건너뛴 경우 결론은 "해당 없음" 으로 보고한다.

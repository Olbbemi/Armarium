# 절대 규칙 태그 검증

이 파일은 overview.md 의 실행 순서에 따라 메인 Claude 가 직접 로드한다.

대상 스킬의 `<PENETRATE>` / `<RICOCHET>` 태그가 `skill-writing §3` 규약을 따르는지 확인한다.
대상 범위는 SKILL.md, overview.md, 그리고 모든 하위 파일이다.

---

## 태그 의미 (요약)

- `<PENETRATE>` -- 절대 수행 규칙 (위반 시 작업 무효). 본문은 "~한다" 형태의 수행 명령.
- `<RICOCHET>` -- 절대 금지 규칙 (위반 시 작업 무효). 본문은 "~하지 않는다 / ~금지" 형태의 금지 명령.

---

## 체크리스트

### 태그 내부 작성 형식

- [ ] 태그 내부에 불릿(`-`, `*`)이 사용되지 않았다
- [ ] 태그 내부에 헤딩(`#`)이 사용되지 않았다
- [ ] 태그 내부에 표가 사용되지 않았다
- [ ] 태그 내부에 의도적인 들여쓰기 구조가 없다
- [ ] 각 태그 블록 안에는 평문 단락 하나만 들어 있다

### 태그 의미 일치

- [ ] `<PENETRATE>` 내부 문장이 수행 명령("~한다") 형태다 (금지 명령이 들어 있지 않다)
- [ ] `<RICOCHET>` 내부 문장이 금지 명령("~하지 않는다", "~금지") 형태다 (수행 명령이 들어 있지 않다)

### 산문 절대 규칙 누락 여부

본문에 절대 규칙처럼 보이는 산문이 있는데 태그로 변환되지 않은 경우를 찾는다.
판단 단서가 되는 표현 예: "반드시", "절대로", "예외 없이", "~하지 마라", "위반 시", "무조건".

- [ ] 본문에 위 단서가 포함된 절대 규칙성 문장 중 태그로 감싸지 않은 항목이 없다

해당하는 산문이 있으면 그 원문을 인용해서 보고한다.

# 구조 검증

이 파일은 overview.md 의 실행 순서에 따라 메인 Claude 가 직접 로드한다.

검증 대상 스킬의 파일/디렉토리 구조가 `skill-writing` 규격을 따르는지 확인한다.
이 단계 실패 시 후속 단계가 의존하는 파일이 없을 수 있으므로 즉시 중단한다.

---

## 단순 vs 복합 판단 기준

대상 스킬 디렉토리 안에 다음 중 하나라도 있으면 복합 스킬로 본다.

- SKILL.md, overview.md 외의 추가 디렉토리가 있다
- SKILL.md, overview.md 외의 추가 마크다운 파일이 있다

판단에서 제외하는 것이 둘 있다.

- `README.md` -- 사람이 읽는 문서이지 스킬 실행 파일이 아니다.
- `wip/` 디렉토리 -- 이 검증이 사전 준비 단계에서 직접 만든 것이라 1단계 시점에 항상 존재한다. 세지 않으면 모든 단순 스킬이 복합으로 오판된다.

해당하지 않으면 단순 스킬로 본다.

---

## 체크리스트

### 공통 (모든 스킬)

- [ ] `skills/<스킬명>/SKILL.md` 파일이 존재한다
- [ ] `skills/<스킬명>/overview.md` 파일이 존재한다
- [ ] SKILL.md 본문이 동작 내용을 포함하지 않는다 (overview 경로 지시와 하위 스킬 로딩 안내만 허용)

### 복합 스킬 추가 확인

- [ ] overview.md 에 `## 하위 스킬` 섹션이 존재한다
- [ ] overview.md 에 `## 실행 순서` 섹션이 존재한다
- [ ] 모든 하위 파일 경로가 overview.md 에 명시되어 있다
- [ ] 명시된 경로가 플러그인 루트 기준으로 작성되어 있다 (예: `skills/<스킬명>/checks/foo.md`)
- [ ] overview.md 에 명시된 모든 경로가 실제 파일과 매칭된다

## 결과 보고

체크리스트 각 항목을 실행한 뒤 아래 형식으로 출력한다.

```
**판정 분류:** 단순/복합

- [o] 항목명
- [x] 항목명 -- 실패 이유

**결론:** 통과/실패 -- 통과 N / 실패 N
**수정 제안:** (실패 항목별 수정 방법, 없으면 생략)
```

<FORBIDDEN>
`[x]` 표기 항목이 하나라도 있는데 결론을 통과로 적지 않는다.
</FORBIDDEN>

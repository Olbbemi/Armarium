# 프론트매터 검증

이 파일은 overview.md 의 실행 순서에 따라 메인 Claude 가 직접 로드한다.

SKILL.md 의 프론트매터가 규격을 따르고, overview.md 및 하위 파일에는 프론트매터가 없는지 확인한다.

---

## 체크리스트

### SKILL.md 프론트매터

- [ ] 프론트매터 블록이 존재한다 (`---` 로 감싸인 YAML)
- [ ] `name` 필드가 있다
- [ ] `description` 필드가 있다
- [ ] `created` 필드가 있다
- [ ] `name` 값이 영문/숫자/하이픈만으로 구성되어 있다
- [ ] `name` 값이 스킬 디렉토리명과 일치한다
- [ ] `created` 값이 `YYYY-MM-DD HH:MM` 형식이다

### overview.md 및 하위 파일

- [ ] overview.md 에 프론트매터가 없다
- [ ] 복합 스킬인 경우 모든 하위 파일에 프론트매터가 없다 (`agents/` 아래 파일은 예외 — 에이전트 정의 파일은 별도 프론트매터 규격을 가지며 `agent-check` 에서 검증)

---

## 결과 보고

체크리스트 각 항목을 실행한 뒤 아래 형식으로 출력한다.

```
- [o] 항목명
- [x] 항목명 -- 실패 이유
  > "문제가 된 원문 인용 (있는 경우)"

**결론:** 통과/실패 -- 통과 N / 실패 N
**수정 제안:** (실패 항목별 수정 방법, 없으면 생략)
```

<PENETRATE>
`[x]` 표기 항목이 하나라도 있으면 결론은 실패다.
</PENETRATE>

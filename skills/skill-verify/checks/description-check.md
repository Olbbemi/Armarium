# Description 검증

이 파일은 overview.md 의 실행 순서에 따라 메인 Claude 가 직접 로드한다.

SKILL.md 의 `description` 필드가 `skill-writing §5` 작성 규칙을 따르는지 확인한다.

---

## 체크리스트

### 포함 여부 (있어야 할 것)

- [ ] 이 스킬이 필요한 상황이나 증상이 기술되어 있다
- [ ] 사용자가 실제로 할 법한 말이나 질문 예시가 포함되어 있다

### 금지 항목 (있으면 안 되는 것)

- [ ] 스킬이 무엇을 하는지 요약하는 문장이 없다 (예: "코드 설계 파이프라인 전체 지도")
- [ ] 워크플로나 절차 설명이 없다 (예: "먼저 X 한 다음 Y 한다")
- [ ] 지시문이 없다 ("~할 것", "~반드시 읽을 것", "~참고할 것" 등)

---

## 판단 가이드

판단이 모호한 경우 다음 기준을 따른다.

- "이 스킬이 필요한 상황" 인지 "스킬이 무엇을 하는지" 인지 헷갈리면, 주체로 판별한다. 주체가 사용자/상황이면 통과, 스킬 본인의 동작이면 실패.
- 따옴표로 묶인 사용자 발화는 포함 항목 충족 근거로 본다.

---

## 결과 보고

체크리스트 각 항목을 실행한 뒤 아래 형식으로 출력한다.

```
- [o] 항목명
- [x] 항목명
  > "문제가 된 원문 인용"

**결론:** 통과/실패 -- 통과 N / 실패 N
**수정 제안:** (실패 항목별 수정 방법, 없으면 생략)
```

<PENETRATE>
`[x]` 표기 항목이 하나라도 있으면 결론은 실패다.
</PENETRATE>

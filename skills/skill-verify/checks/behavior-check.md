# 동작 검증

이 파일은 overview.md 의 실행 순서에 따라 메인 Claude 가 직접 로드한다.

대상 스킬을 실제로 호출했을 때 의도된 로드 흐름이 정상 작동하는지 시뮬레이션한다.
structure-check 가 정적 존재 확인이라면, behavior-check 는 Read 툴로 실제 로드를 시도한다.

---

## 실행 절차

### 1. SKILL.md 로드

대상 스킬의 SKILL.md 를 Read 툴로 로드한다.

- 정상 로드되는가
- 본문에 overview.md 경로 지시가 명시되어 있는가
- 명시된 경로가 플러그인 루트 기준인가

### 2. overview.md 로드

SKILL.md 가 지시하는 overview.md 경로를 Read 툴로 로드한다.

- 정상 로드되는가
- 파일이 비어 있지 않은가 (실질적인 내용이 있는가)

### 3. 하위 파일 로드 (복합 스킬인 경우)

overview.md 에서 명시한 모든 하위 파일을 Read 툴로 순차 로드한다.

- 명시된 모든 경로에 대해 로드가 성공하는가
- 각 파일이 비어 있지 않은가

에이전트 정의 파일의 존재는 이 검사가 보지 않는다. 정적 확인이라 `agent-check` 소관이며, 여기서 또 보면 같은 항목이 두 보고서에 실린다.

<FORBIDDEN>
실제 Task 호출은 하지 않는다.
</FORBIDDEN>

---

## 체크리스트

- [ ] SKILL.md 가 정상 로드되었다
- [ ] SKILL.md 가 지시하는 overview.md 경로로 로드가 성공했다
- [ ] overview.md 가 빈 파일이 아니다
- [ ] (복합 스킬) overview.md 가 참조하는 모든 하위 파일을 로드할 수 있다
- [ ] (복합 스킬) 모든 하위 파일이 빈 파일이 아니다

해당하지 않는 항목은 "해당 없음" 으로 표기한다.

---

## 결과 보고

체크리스트 각 항목을 실행한 뒤 아래 형식으로 출력한다.

```
- [o] 항목명
- [x] 항목명 -- 실패 이유
  위치: <파일 경로>
- [-] 항목명 (해당 없음)

**결론:** 통과/실패 -- 통과 N / 실패 N / 해당 없음 N
**수정 제안:** (실패 항목별 수정 방법, 없으면 생략)
```

<FORBIDDEN>
`[x]` 표기 항목이 하나라도 있는데 결론을 통과로 적지 않는다.
</FORBIDDEN>

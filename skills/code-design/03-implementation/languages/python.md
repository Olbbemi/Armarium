# Python 고유 가드레일과 검증 도구

각 항목이 스켈레톤의 어느 축에서 왔는지는 아래와 같다. 축에 해당 항목이 없으면 그 언어에서 비자명하지 않다는 뜻이다.

| 출처 축 | 해당 항목 |
|---------|----------|
| 자원 · 수명 | PY-G1 · PY-G2 |
| 타입 · 인터페이스 표면 | PY-G3 · PY-G4 |
| 빌드 · 진단 | PY-G5 · PY-G6 |
| 동시성 프리미티브 | PY-G7 · PY-G8 |
| 테스트 조직 | 없음 -- 프로덕션과 가르는 방식이 다른 언어와 다르지 않다 |
| 12종 | 아래 "검증 12종 -- Python 에서 쓰는 도구" |

- **PY-G1. 기본 인자에 리스트 · 딕트 같은 가변 객체를 쓰지 않는다 -- `None` 을 기본값으로 두고 함수 안에서 만든다.**
  기본값은 호출할 때마다가 아니라 함수를 정의할 때 한 번만 평가되어, 그 객체가 호출 사이에 계속 살아 남는다.

- **PY-G2. 파일 · 소켓 · 락처럼 해제가 필요한 자원은 `with` 로 잡는다.**
  참조 카운트가 0이 되는 시점에 기대면 순환 참조나 예외 경로에서 해제가 밀리고, CPython 에서 잘 닫히던 코드가 다른 구현에서 깨진다.

- **PY-G3. 패키지의 공개 표면을 `__all__` 로 명시한다.**
  이름 앞 밑줄은 관례일 뿐 접근을 막지 못해, 명시하지 않으면 내부용 이름까지 공개 표면이 된다.

- **PY-G4. 공개 함수 · 메서드의 인자와 반환에 타입 힌트를 붙인다.**
  시그니처가 실행 중에만 드러나므로, 힌트가 없으면 호출자가 계약을 읽을 곳이 없다.

- **PY-G5. 타입 검사기와 린터 통과를 완료 조건에 넣는다.**
  컴파일 단계가 없어 이것을 돌리지 않으면 그 줄이 실행될 때까지 어떤 오류도 드러나지 않는다. (검증 완료선 "무경고" 의 Python 구체화.)

- **PY-G6. 예외를 잡을 때 대상을 지정한다 -- `except:` 나 `except BaseException` 으로 통째로 잡지 않는다.**
  `KeyboardInterrupt` · `SystemExit` 까지 삼켜 종료가 막히고, 실행 중 오류가 유일한 진단 통로인데 그것을 닫는다.

- **PY-G7. CPU 를 쓰는 작업을 스레드로 나눠 빠르게 만들려 하지 않는다 -- 프로세스나 네이티브 확장으로 뺀다.**
  GIL 이 바이트코드 실행을 직렬화해 스레드를 늘려도 CPU 작업의 총 시간이 줄지 않는다. I/O 대기는 해당 없다.

- **PY-G8. GIL 이 있어도 공유 가변 데이터는 락으로 보호한다.**
  GIL 은 바이트코드 하나의 단위만 보장하고 `x += 1` 같은 복합 연산은 여러 바이트코드로 쪼개져, 그 사이에 스레드가 바뀌면 갱신이 사라진다.

## 검증 12종 -- Python 에서 쓰는 도구

`verification.md` 가 각 종류에서 "언어별로 갈리는 곳" 으로 지목한 자리를 Python 으로 채운 것이다. 프로젝트가 이미 쓰는 도구가 있으면 그것을 따르고, 없을 때의 기본값으로 본다.

| 종류 | 도구 | 메모 |
|------|------|------|
| 기능 | 유닛과 같은 러너 | 승인 기준을 유닛과 e2e 로 나눠 담으므로 전용 도구가 없다 |
| 성능 | cProfile (프로파일) · pytest-benchmark (마이크로) | 인터프리터 웜업과 GC 시점으로 편차가 크므로 반복 횟수를 고정하고 중앙값을 본다 |
| 보안 | pip-audit (의존성 CVE) · bandit (소스 패턴) | 둘은 보는 대상이 달라 함께 켠다 |
| 호환성 | 공개 API 시그니처 비교 | 순수 Python 에는 ABI 가 없어 소스 수준 호환만 본다. C 확장을 쓰면 그 확장이 별도로 ABI 대상이다 |
| 수동 QA | N/A | 사람이 하는 확인이라 언어와 무관하다 |
| e2e | 언어 무관 -- 진입 스크립트를 프로세스로 띄워 확인한다 | |
| 유닛 | pytest (또는 표준 라이브러리 unittest) | |
| 통합 | 유닛과 같은 프레임워크 + 픽스처 | |
| 경합 | 전용 검출 도구 없음 | TSan 에 해당하는 것이 없어 반복 · 부하 실행으로만 잡힌다. PY-G8 을 코드에서 지키는 것이 유일한 예방이다 |
| 계약 | Python 고유 도구 없음 | 스키마 언어(protobuf 등)를 쓰면 그쪽 생성기를 따른다 |
| 경계값 | 유닛에 흡수 | 정수가 임의 정밀도라 오버플로 경계가 없다. 대신 부동소수 정밀도와 빈 컬렉션 · `None` 이 경계다 |
| 정적 분석 | ruff (린트) · mypy (타입) | 보는 축이 달라 하나로 대체되지 않는다. PY-G5 가 요구하는 것이 이 둘이다 |

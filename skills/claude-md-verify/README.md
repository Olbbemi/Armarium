# claude-md-verify

그 프로젝트의 CLAUDE.md 품질을 검증하는 단순 스킬.

## 무엇을 하나

대상 프로젝트의 CLAUDE.md 를 16개 품질 항목으로 점검하고, 각 결함에 고침 제안을 붙여
`<프로젝트 루트>/claude-md/result.md` 보고서로 낸다. 에이전트 없이 메인이 직접 수행하며,
파일을 직접 고치지는 않는다.

검증 항목은 네 묶음이다.

- 형식 / 구조: 마크다운 구조화, 개행·문단 분리, 리스트화, 섹션 밀도, 이모지 배제, 불릿 남용, 헤딩 vs bold 구분
- 언어 / 표현: 은유 배제, 모호·집행 불가, 직설·간결
- 의미 / 논리: 규칙 충돌, 중복, 근거 유무, 자기완결성, 적용 범위·트리거 명확성
- 정합성: 프로젝트 실제와의 정합(stale 참조)

## 호출

명시 호출 전용. `/claude-md-verify`, "이 CLAUDE.md 검증해줘".

## 왜 독립 스킬인가

skill-verify 는 스킬이 skill-writing 규격대로인지 보는 스킬 전용 검증기다. CLAUDE.md 는
스킬이 아니라 각 프로젝트의 지침 파일이라 대상·기준·실행 맥락이 다르다. 그래서 별도 스킬로
두고, 검증 기준도 이 스킬이 자체 소유한다(skill-writing 비의존).

## 판정 기준

결함: 한 문장의 길이가 100자를 넘는다.

문장 끝은 마침표, 물음표, 느낌표로 판정한다. 코드블록과 표 안은 대상이 아니다.

## 수정 지침

조건절을 앞 문장으로 떼거나, 나열을 리스트로 내린다.
길이를 맞추려고 필요한 조건이나 예외를 지우지 않는다.

## 예시

<!-- case: pass -->
```
결함: 파일 줄 수가 200 을 넘는다.
```

<!-- case: fail -->
```
결함은 조건과 예외와 근거가 한 호흡에 뭉쳐 있어 어디까지가 조건이고 어디부터가 결론인지 조건과 예외와 근거가 한 호흡에 뭉쳐 있어 어디까지가 조건이고 어디부터가 결론인지 읽는 쪽마다 다르게 끊어 읽게 되는 문장이다.
```

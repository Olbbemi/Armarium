---

## 판정 기준

결함: 같은 부모 아래 같은 레벨의 헤딩들 중 일부만 선행 번호(`1.`, `2.` 형태)를 갖는다.

전부 번호가 있거나 전부 없으면 통과다. 형제 헤딩이 하나뿐이면 판정하지 않는다.

## 수정 지침

번호 없는 헤딩이 실제로는 앞 절의 하위 내용이면 레벨을 한 단계 내린다.
정말 형제면 번호를 붙인다.

## 예시

<!-- case: pass -->
```
## 1. 첫째
## 2. 둘째
```

<!-- case: fail -->
```
## 1. 첫째
## 2. 둘째
## 실행 순서
```

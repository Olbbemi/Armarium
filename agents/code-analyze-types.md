대상 코드의 **타입/관계 facet** (facet 2)을 추출해 마크다운 본문으로 반환한다.

## 입력
분석 대상 경로. 호출자(메인)가 명시 전달한다.

## 추출 항목
- **타입 정의**: 구조체/클래스/인터페이스/열거형 등. 이름, 종류, 주요 멤버(필드/메서드 시그니처).
- **관계**: 상속, 인터페이스 구현, 포함/합성 관계.

## 출력 형식
마크다운. 관계는 **Mermaid `classDiagram` 블록**으로 표현. 타입이 많으면 핵심 타입(도메인/공개 인터페이스) 위주로 추리고, 사소한 내부 타입의 과도 나열은 피한다.

## 범위
모듈 레이아웃/의존(facet 1), 플로우(3), 외부 라이브러리(4), 품질(6)은 다루지 않는다.

<RICOCHET>
결과를 직접 파일로 저장하지 않는다. 마크다운 본문으로 반환하고 저장은 메인이 한다.
</RICOCHET>

분석 대상의 **프로젝트 고유 관례**를 실제 코드에서 관찰해 관례 facet 본문(§1~3)으로 반환한다. 관례는 "이 프로젝트/팀이 실제로 이렇게 짠다"는 고유색이다 -- 언어 표준이나 보편 원칙이 아니라, 이 코드베이스에서 반복적으로 관찰되는 네이밍·이디엄·함정이다. 다른 가로지르는 facet 처럼 **본문을 반환하고 메인이 저장**한다(직접 Write 아님).

## 입력 (메인이 전달)
- **스켈레톤**(`<브랜치 디렉토리>/facet/skeleton.md`) -- 파일 트리·인벤토리·노드 이름의 단일 출처. 관례를 노드로 링크할 때 이 노드 이름(=ID)을 쓴다.
- **대상 경로** -- 실제 소스. 관례는 여기서 관찰한다.
- **언어별 규칙 파일**(`skills/code-analyze/languages/<언어>.md`, 있으면) -- 언어 고유 노드 단위·어휘. 자기 소비 섹션이 있으면 로드한다.
- **브랜치 디렉토리** 경로 -- 노드 링크의 상대경로 기준.

## 산출 (본문 반환)
아래 **고정 섹션 틀**(제목·순서 통일, 각 섹션 존재 조건부 -- 관찰된 게 없으면 그 섹션은 "해당 없음"으로 두거나 비운다)로 마크다운 본문을 반환한다. 메인이 이 본문에 §4(분석 스킵 기록)를 붙여 `facet/conventions.md` 로 저장한다.

### §1. 네이밍 규칙
파일/타입/함수/디렉토리의 명명에서 관찰되는 규칙 -- 케이스(예: 타입은 PascalCase, 자유 함수는 snake_case), 접두/접미 규칙, 도메인 어휘(같은 개념을 부르는 고정 단어), 축약 관습. 실제로 쓰인 사례에 근거해 규칙을 서술한다.

### §2. 반복 패턴 / 이디엄
이 코드베이스가 반복해 쓰는 방식 -- 에러 처리 방식, 자원 관리 이디엄, 모듈/디렉토리 배치 관습, 경계 넘는 방식 등. 각 패턴은 **그 패턴이 드러나는 구조 노드로 링크**해 독자가 실물을 보게 한다.

### §3. 함정 (gotchas)
코드를 만질 때 걸리는 **비자명한 함정** -- 놀라운 동작, 순서 제약("A 를 B 보다 먼저"), 하면 안 되는 것, 겉과 다른 실제. 각 함정은 관련 구조 노드로 링크한다.

## 관찰 기반 (지어내기 금지)
관례는 실제 코드에서 **관찰**해 인스턴스화한다. 보편 규칙("함수는 짧게" 등)을 부과하지 않고, 이 코드베이스에서 반복적으로 확인되는 것만 적는다. 근거가 없으면 적지 않는다(빈 섹션이 틀린 서술보다 낫다).

<FORBIDDEN>
보편 규칙이나 코드 근거 없는 추정을 관례로 지어내지 않는다.
</FORBIDDEN>

## 교차링크 = 노드 ID (자기기준 상대경로)
§2 패턴·§3 함정이 구조 노드를 가리킬 때, 소스 파일명이 아니라 **스켈레톤이 정한 노드 이름(=ID)**으로, 링크가 적힌 파일 자신 기준의 상대경로로 링크한다(facet 교차링크 규약). render-data 가 이 링크를 노드 ID 로 해석해 `conventions.patterns[].relatedNodes`·`conventions.pitfalls[].relatedNodes` 를 만든다.

## 경계 (다른 facet 과 겹치지 않음)
- **invariants 와 구분** -- invariants 는 검증 가능한 전칭 규약(항상 참인 것)이다. 관례는 검증 대상이 아닌 고유색(네이밍·스타일·이디엄·함정)이다. 같은 사실을 양쪽에 적지 않는다.
- **구조 노드 상세 재서술 금지** -- 타입/시그니처/멤버는 구조 문서가 단일 출처다. 관례는 그것을 링크만 하고 다시 쓰지 않는다.

<FORBIDDEN>
구조 노드의 시그니처/멤버나 invariants 의 전칭 규약을 관례 facet 에 재서술하지 않는다(링크로 갈음).
</FORBIDDEN>

## §4 는 이 에이전트 밖
§4(분석 스킵 기록 -- 무엇을 왜 뺐나)는 착수 전 게이트에서 메인이 사용자와 확정한 산물이라, 메인이 저장 시 붙인다. 이 에이전트는 §1~3 만 낸다.

<FORBIDDEN>
§4 분석 스킵 기록을 이 에이전트가 작성하지 않는다(메인이 게이트 확정본으로 붙인다).
</FORBIDDEN>

## 출력
§1~3 마크다운 본문을 반환한다. 저장은 메인이 한다.

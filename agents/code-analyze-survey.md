코드를 훑어 **골격(skeleton)** 한 장을 만들어 본문으로 반환한다. 골격은 이후 모든 분석 에이전트가 공유하는 **단일 진실 출처**다 -- 개수/인벤토리/모듈 목록을 여기서 1회 확정하고, 뒤 단계는 그 위에 깊이만 더한다.

> 이 에이전트는 **규모 적응**으로만 쓴다. 트리가 작으면 메인이 직접(Bash/Glob) 골격을 만든다. 이 에이전트는 트리가 커서 메인 컨텍스트를 보호해야 할 때 위임용이다.

## 입력
- 분석 대상 경로(소스 트리 루트).
- 분석 대상 언어 + `skills/code-analyze/languages/<언어>.md` 경로(메인이 판정해 전달). 그 파일이 있으면 **"노드 단위" 섹션**을 로드해 인벤토리/개수 셀 때 적용한다. 없으면(미지원 언어) 범용 규칙만 쓴다.

## 산출 (skeleton.md 본문)
골격 머리에 **대상 언어**(메인이 판정해 전달한 이 모듈의 단일 언어)를 한 줄 명시한다 -- 언어별 규칙 파일 로드와 callgraph 슬롯 선택의 기준.

1. **파일 트리** -- 소스 트리를 미러링한 경로 목록(분석 대상 소유 파일만; 벤더/서드파티 디렉토리 제외). 구조 facet 의 노드 문서 경로가 여기서 결정적으로 정해진다.
2. **모듈/레이어 목록** -- 파일 트리를 상위 디렉토리/네임스페이스 단위로 묶은 모듈/레이어(이름 + 소속 파일 범위). architecture 의 모듈 서사와 callgraph 오버뷰가 공유하는 단위라, 여기서 1회 확정해 단일 출처로 둔다.
3. **파일별 인벤토리** -- 각 소스 파일이 담은 타입/함수의 **이름과 개수**(시그니처 상세는 적지 않음 -- 그건 Stage 1 구조 에이전트 몫). "노드=파일" 단위(선언/정의가 분리된 언어면 언어 파일 "노드 단위" 규칙대로 짝을 한 노드로 묶어 센다).
4. **진입 표면** -- 프로그램이 외부에서 구동되는 지점 목록(예: 실행 진입점, 진입표면->핸들러 매핑의 표면 쪽 -- CLI 서브커맨드 / HTTP 라우트 / 메시지 토픽 / 공개 API 중 해당하는 것).
5. **데이터 계약 존재** -- 영속/설정 스키마(DB 스키마, 마이그레이션, 설정 파일 포맷 등)가 있으면 그 위치만 표시(상세는 data-contract 몫).
6. **테스트 존재** -- 테스트 디렉토리/파일이 있으면 위치/개수만.
7. (언어별) **호출/참조 맵** -- 언어별 callgraph 보조가 돌았으면 그 시드를 여기 붙여 flow 추적 출발점으로 둔다.

## 카운팅 규율 (필수)
1. 셀 단위를 먼저 못 박는다(무엇을 포함/제외하는지 정의를 명시).
2. 숫자를 freehand 로 적지 않는다 -- 구성원 목록을 먼저 만들고 **개수 = 목록 길이**.
3. 모든 나열은 재현가능한 검색/도구 결과에 근거한다(언어별 수단은 네가 선택: glob/grep/ctags/AST 등). 어떤 도구로 셌는지 한 줄 남긴다.
4. 헤드라인/합계로 적은 숫자는 인벤토리 목록의 행수와 **자가 교차검산**한다 -- 어긋나면 목록을 진실로 삼아 합계를 고친다(헤드라인 산술이 목록과 따로 틀릴 수 있다).

## 성격
의도(설계)가 아니라 실제 짜인 현실(as-built)을 센다. 깊이가 아니라 **목록과 개수**가 목표다.

## 출력
완성된 골격 전체를 본문으로 반환한다. 저장은 메인이 `analyze/facet/skeleton.md` 에 한다.

<PENETRATE>
개수/인벤토리/모듈 목록은 재현가능한 도구 결과에 근거해 목록으로 먼저 만들고 개수=목록 길이로 적는다.
</PENETRATE>

<PENETRATE>
헤드라인/합계 숫자를 인벤토리 목록 행수와 교차검산하고, 어긋나면 목록을 진실로 삼아 합계를 고친다.
</PENETRATE>

타입/함수의 시그니처·역할 같은 깊은 상세를 골격에 적지 않는다(그건 Stage 1 몫).
</RICOCHET>

<RICOCHET>

</RICOCHET>

</RICOCHET>

배정받은 **슬라이스**(구조 서브트리 하나, 또는 가로지르는 문서 묶음)를 인터랙티브 HTML **페이지들**로 렌더해 `analyze/html/` 아래에 **직접 Write** 한다. 결과 HTML 을 본문으로 반환하지 않는다 -- 본문 반환은 큰 산출에서 단일 응답 토큰 한도에 걸려 잘리므로(이 스킬이 겪은 결함), 렌더 산출은 에이전트가 직접 저장한다.

## 입력 (메인이 전달)
- **슬라이스 지정**: (a) 구조 서브트리면 그 서브트리의 facet 파일노드 문서 경로 목록, (b) 가로지르는 묶음이면 `architecture/flow/data-contract/test/externals/invariants` facet 문서.
- **페이지별 PREFIX**: 메인이 각 페이지의 html 기준 디렉토리깊이로 계산한 `"../" * 깊이` 문자열. **자산·사이드바(data-root)** 를 이걸로 적는다(교차링크는 PREFIX 가 아니라 facet 상대링크 보존 -- 아래). 깊이 산수는 메인이 끝냈으니 에이전트는 PREFIX 를 그대로 붙이기만 한다.
- **페이지 셸 템플릿**: head(공유 자산을 `{PREFIX}assets/style.css`·`{PREFIX}assets/script.js` 로 참조) + `<body data-root="{PREFIX}">` + 사이드바 컨테이너 + 콘텐츠 슬롯. 메인이 소유하는 공유 셸의 일부다.
- **출력 경로 스킴**: facet 경로를 미러한다(구조 노드 = `html/<소스미러>/<노드>.html`, 가로지르는 = `html/<문서>.html`).
- **링크 스킴 (두 세계 분할)**: (1) 자산·사이드바 = `{PREFIX}assets/...`·`data-root="{PREFIX}"`. (2) 파일 간 교차링크 = facet 의 **자기기준 상대링크**를 `.md` -> `.html` 치환만 해 보존(PREFIX 부착·깊이 재계산 없음 -- html 이 facet 구조를 미러하므로 그대로 유효). 같은 페이지 안 앵커는 `#<앵커>` 그대로.
- `analyze/.tmp/flow.diagram.md`(있으면, 플로우 슬라이스), `analyze/.tmp/` 의 호출 그래프 SVG(있으면).

## 산출 (직접 Write)
- 슬라이스의 각 단위를 **한 페이지로** 쓴다 -- 구조 슬라이스는 **파일노드당 `.html` 한 장**(전체 시그니처/속성 **상세 유지**), 가로지르는 슬라이스는 **문서당 `.html` 한 장**.
- 각 페이지는 셸 템플릿을 채워 만든다(head 자산은 `{PREFIX}assets/...`, body 는 `data-root="{PREFIX}"`). 공유 `style.css`/`script.js` 는 **참조만** 하고 인라인 복사하지 않는다(다중 파일이라 자체완결이 아니다).
- mermaid 블록은 공유 `script.js` 가 렌더하도록 약속된 컨테이너(예: `<div class="mermaid">`)로 둔다. 사전 렌더 호출그래프 SVG 는 그대로 인라인.
- **교차링크 보존(필수)**: facet 의 핵심 내용과 링크(플로우->구조 노드, externals->어댑터, test->invariants 등)를 **작동하는 파일 간 href** 로 살린다. facet 의 자기기준 상대링크를 `.md` -> `.html` 치환만 해 보존하고, 링크마다 깊이를 다시 세거나 PREFIX 를 붙이지 않는다(html 이 facet 구조를 미러하므로 그대로 유효). 끊긴 링크를 두지 않는다.

## 사람용 재포맷 (facet 텍스트를 그대로 옮기지 않는다)
facet 은 Claude 용 고밀도 데이터고, HTML 은 **사람 독자**다. facet `.md` 문장에 태그만 입혀 글자 그대로 옮기면(번역기) 사람이 읽기 힘들다 -- 같은 데이터를 사람이 읽는 모양으로 **재포맷**한다. 단 **내용(데이터)은 facet 와 동치로 보존**한다 -- 요약하거나 빼지 않는다(facet=단일 진실, HTML=충실 뷰). 바꾸는 건 표현뿐이다.

재포맷은 다음 모양으로 한다(레시피).
- **표/칸**: 표의 각 칸은 짧은 요지 한 줄이다. 긴 설명·SQL·코드 스니펫은 칸에 넣지 말고 표 **아래** 별도 코드블록(`<pre><code>`)이나 문단으로 분리한다.
- **순서·플로우**: 호출 순서 같은 선형 흐름은 번호 리스트(`<ol>`)로, 분기·생명주기는 mermaid 다이어그램으로 표현한다(문장 속 인라인 ASCII `A -> B -> C` 나열 대신).
- **교차링크 위치**: 사이트 네비는 사이드바가 맡으므로, 페이지 안 교차링크는 본문 **하단 "관련/참고" 섹션**에 모은다. 문장 중간 인라인 링크는 핵심 1:1 관계(구현<->포트) 한둘만 둔다.

facet 작성 측(structure 등)은 지금처럼 핵심 데이터를 고밀도로 담아도 된다 -- 그건 Claude 용이라 OK. 사람용 가공은 이 render 단계가 맡는다.

<PENETRATE>
facet 의 같은 데이터를 보존한 채 사람용으로 재포맷한다 -- 표 칸은 짧은 요지(긴 것/SQL/코드는 표 밖 코드블록), 선형 흐름은 `<ol>`·분기는 mermaid, 교차링크는 하단 "관련/참고" 섹션에 모은다.
</PENETRATE>

<RICOCHET>

</RICOCHET>

<RICOCHET>

</RICOCHET>

## 그래프 절제 (callgraph 슬라이스 등)
진입점마다 기계적으로 드릴다운 1장을 만들지 않는다. 의미상 다른 진입점만 남기고, 거의 동형인 묶음은 대표 1~2장 + 차이 표로 갈음한다. 드릴다운처럼 부피 큰 다이어그램은 기본 접힘(`<details>`)으로 두고, 개요 그래프만 기본 노출한다.

## mermaid 소스 안전 (필수)
두 가지를 반드시 한다.

**(1) 노드/엣지 라벨은 항상 따옴표로 감싼다.** flowchart/graph 의 노드 라벨(`A["..."]`)과 엣지 라벨(`-->|"..."|`)을 **예외 없이** 따옴표로 감싼다 -- "특수문자가 있을 때만"이 아니라 무조건이다. 라벨 안의 `( ) [ ] { } |` 같은 문자가 mermaid 파서에서 인접 노드/구문과 충돌해 깨지는데(실측: `B -->|false (force=true)| G[...]` 가 parse 실패), 어떤 문자가 위험한지 매번 판단하면 반드시 하나를 흘린다. 무조건 따옴표가 robust 하다. (라벨에 따옴표 자체가 들어가면 mermaid 엔티티 `#quot;` 로 표기 -- 드묾.)

**(2) 브라우저가 태그로 먹을 `<` 는 `&lt;` 로 이스케이프한다.** 컨테이너에 넣은 mermaid 소스 안의 `<` 중 브라우저가 HTML 태그로 파싱할 수 있는 것(예: classDiagram 스테레오타입 `<<interface>>`/`<<enumeration>>`)은 `&lt;` 로, 짝 `>` 는 `&gt;` 로 이스케이프한다(규칙: `<` 뒤에 글자/`/`/`!`/`?` 가 오면 이스케이프).

**Write 전 자가점검**: 각 mermaid 블록에서 (1) 따옴표로 안 감싼 노드/엣지 라벨이 없는지(특히 라벨 텍스트에 raw `( ) [ ] { } |` 노출), (2) raw `<[A-Za-z/!?]` 가 없는지 점검한다.

## 출력
배정 슬라이스의 페이지들을 직접 Write 한 뒤, **쓴 파일 경로 목록만** 짧게 본문으로 반환한다(HTML 내용은 반환하지 않는다).

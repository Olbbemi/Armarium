대상 코드의 **로직요약 facet** (facet 5)을 추출해 마크다운 본문으로 반환한다.

## 입력
분석 대상 경로. 호출자(메인)가 명시 전달한다.

## 추출 항목
- **모듈/주요 컴포넌트가 무엇을 하는지**를 코드가 아닌 사람 말로 서술. "이 모듈은 ~를 받아 ~를 한다" 수준.
- 핵심 책임과 협력 관계 위주. 줄 단위 코드 해설은 하지 않는다.
- **부수 효과**: 파일 I/O, 네트워크 호출, DB 변경, 외부 명령 실행 등 외부 세계에 영향을 주는 동작과 그 위치.
- **가정과 제약**: 코드가 전제하는 입력/환경 조건, 의도적으로 다루지 않는 케이스.

## 출력 형식
마크다운. 모듈별 짧은 서술 단락(또는 불릿). 다른 facet(구조/타입/플로우)과 중복되는 기계적 나열 대신, "의도/책임"을 사람 말로.

## 범위
구조(facet 1), 타입(2), 플로우(3), 외부(4), 품질(6)의 형식적 데이터는 다루지 않는다. 여기서는 "사람 말 요약"만.

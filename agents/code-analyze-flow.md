시스템의 **플로우**(end-to-end 경로)를 망라해 본문으로 반환한다. 각 플로우 문서는 **척추**(호출 순서/분기/데이터 변환)만 담고, 각 노드 내부 상세(시그니처/역할/불변식)는 구조 노드 문서로 **링크**한다.

## 플로우 정의 / 열거 경계
한 플로우 = 다음 중 하나에 앵커된 end-to-end 경로:
- (a) **외부 트리거** -- 진입 표면 호출/이벤트 하나당 하나.
- (b) **생명주기** -- 상태 단위의 생성 -> 전이 -> 소멸(예: 세션이 들어와 만들어지고, 나간다는 이벤트에 종료/삭제되는 경로).

열거 경계 = 트리거 수 + 생명주기 수(골격의 진입 표면에서 도출). **표본 추출 금지** -- 어떤 트리거/생명주기도 빠뜨리지 않는다.

## 커버리지/깊이 규율
**망라는 커버리지 기준이지 분량 기준이 아니다.** 모든 트리거/생명주기가 등장하되, 깊이는 복잡도 비례 -- 사소한 CRUD 는 한 줄, 복잡한 경로(다단계 충돌/반복 전개/read-modify-write 등)는 풀 상세.

시퀀스 다이어그램의 **개수**도 복잡도 비례다 -- 복잡한 경로에만 다이어그램을 그리고, 사소한 CRUD 는 산문 한 줄로 끝낸다. 망라는 산문 커버리지로 채우지 다이어그램 장수로 채우지 않는다.

## 입력
- `analyze/facet/skeleton.md` (진입 표면 + 호출/참조 맵 시드 -- 언어별 callgraph 보조가 있으면 그 산출이 출발점).
- 분석 대상 경로.

## 산출
- **산문(척추)** -- `flow.md` 로 영구 저장될 본문.
- **시퀀스 다이어그램** -- Claude 층에 무거우므로 facet 에 영구 저장하지 않고 임시 렌더용으로 분리.
- 둘을 `%%FLOW-DIAGRAMS%%` 구분자로 나눠 반환한다(위=산문, 아래=시퀀스 + 각 다이어그램 첫 줄 `%% 시나리오 N`).
- 시퀀스 메시지 텍스트에는 `;` 를 넣지 않는다 -- mermaid 시퀀스에서 `;` 는 statement separator 라 메시지가 끊겨 렌더가 깨진다. 필요하면 다른 문자(쉼표/줄바꿈)로 바꾼다.

## 성격
하위 모듈을 가로지르는 경로를 전체-뷰로 추적한다. as-built.

## 출력
구분자로 나눈 본문을 반환한다. 메인이 산문을 `analyze/facet/flow.md`, 시퀀스를 `analyze/.tmp/flow.diagram.md` 로 저장한다.

</PENETRATE>

</RICOCHET>

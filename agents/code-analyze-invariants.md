코드 전체를 가로지르는 **규약/불변식**을 캐내 본문으로 반환한다. 한 파일/타입에 안 붙는 **창발적 전역 규칙**이 대상이다(예: 시간/단위 표현 규약, 오류 신호 방식, 동시성/상태 전이 규칙, 경계 변환 규약). 이 문서가 불변식의 **단일 소스**이고, test/architecture 는 여기로 링크만 한다.

> 왜 중요한가: 불변식은 TDD의 금광이다. 전칭 명제 1개 = 프로퍼티 테스트 1개, 분기형 불변식 1개 = 테스트 행렬 1벌, 그리고 "결과가 만족해야 할 조건"이라 테스트 오라클을 공짜로 준다.

## 입력
- `analyze/facet/skeleton.md`.
- 분석 대상 경로.

## 산출 (invariants.md 본문)
불변식마다:
- **진술** -- 전칭 형태로("모든 X 에 대해 ...가 성립한다").
- **범위** -- 어디까지 적용되나(전 모듈 / 특정 경계).
- **강제 지점** -- 코드 어디서 지켜지나(구조 노드 문서로 링크).
- **테스트 가능성** -- 프로퍼티 테스트인지 / 분기 행렬인지 / 단언 모양은 무엇인지(TDD 작성자가 바로 옮기게).

## 핵심 규율: 불변식 vs 단순 관례
모든 관례가 불변식이 아니다. **전칭이면서 검증 가능한 것만** 불변식으로 올린다(금광은 여기). 스타일/관습은 "관례" 절에 따로, 테스트 대상 아님으로 표시한다.

## 성격
의도가 아니라 as-built 로 실제 코드가 지키는 규칙을 캔다. 추측한 규칙이 아니라 코드 근거가 있는 것만.

## 출력
완성 본문을 반환한다. 저장은 메인이 `analyze/facet/invariants.md` 에 한다.

<PENETRATE>
전칭 + 검증 가능한 것만 불변식으로 올리고, 각 불변식에 단언 모양(프로퍼티/분기 행렬)을 적는다.
</PENETRATE>

<PENETRATE>
강제 지점 등 다른 facet/노드로의 교차링크는 이 문서 파일 자신을 기준으로 한 상대경로로 적는다(facet 루트·프로젝트 루트 기준 금지) -- html 이 facet 구조를 미러해 render 가 `.md` -> `.html` 보존만으로 살린다.
</PENETRATE>

<RICOCHET>
검증 불가능한 스타일/관습을 불변식으로 올리지 않는다.
</RICOCHET>

<RICOCHET>
강제 지점의 구현 상세(시그니처/멤버)를 재서술하지 않는다.
</RICOCHET>
